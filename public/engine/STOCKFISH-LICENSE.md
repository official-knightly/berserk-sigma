# Stockfish.js browser engine

- Engine: Stockfish.js 19.0.1, lite single-threaded WebAssembly build
- Upstream: https://github.com/nmrugg/stockfish.js/tree/v19.0.1
- Original chess engine: https://github.com/official-stockfish/Stockfish
- License: GNU General Public License, version 3 (GPL-3.0)
- Copyright and author notices: see stockfish-COPYING.txt and stockfish-AUTHORS.txt
- Complete corresponding source: https://github.com/nmrugg/stockfish.js/archive/refs/tags/v19.0.1.zip

The JavaScript loader and WASM file are a matched pair and must remain together in this directory.
This application starts the engine in a browser Web Worker using the UCI protocol.
